\subsection{Task understanding}
The project targets SemEval-2027 Task 3: Semantic Change Across Multiple Time Periods. The current official development release is Swedish-only, and the objective is to build a reusable foundation for diachronic sense induction and temporal semantic-change analysis before implementing downstream baselines.

The core supervised signal for the later system is not a standard single-label classification task. Instead, the project must handle unsupervised sense induction for Subtask 1 and binary hypothesis-driven usage detection for Subtask 2.
