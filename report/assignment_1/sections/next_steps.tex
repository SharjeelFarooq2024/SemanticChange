\subsection{Next steps}
The next phase compares transparent classical baselines (Logistic Regression, Linear SVM, Complement Naive Bayes, Random Forest, and word-identity ablation) with frozen pretrained representations while keeping all preprocessing modular and reusable. For classical models, both linear coefficients and tree-based Gini feature importances are analyzed to connect feature utility directly back to exploratory data analysis findings. For Baseline B, XLM-R is used as a frozen feature extractor without fine-tuning, evaluating whether contextual embeddings improve discriminability on lexically difficult words.
