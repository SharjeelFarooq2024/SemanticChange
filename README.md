# Semantic Change Across Multiple Time Periods

Swedish usage classification and semantic change experiments for SemEval-2027 Task 3.

The selected model is the word-aware hybrid in `Assignment_3/runs/advanced_hybrid`. Its official F1 is **0.666339 ? 0.021437** across five grouped development splits. Pooled macro F1 is **0.828844** and accuracy is **0.844255**. These are distinct metrics; official F1 has not reached 0.8. The development splits were previously inspected, so these are not hidden-test results.

Use [Assignment 3 execution instructions](Assignment_3/RUNNING.md), [final model scores](Assignment_3/results/model_scores.csv), and the [final reproducibility package](Assignment_3/final_package.zip). Baseline and ablation evidence remains in `Assignment_3/runs/completed` for the assignment comparisons. Discarded model trials and duplicate result packages have been removed.

Install dependencies with `python -m pip install -r requirements.txt`. Run commands from the repository root.

```powershell
# Predict using the selected model; --checkpoint is optional.
python -B Assignment_3/scripts/infer.py --input Assignment_3/runs/completed/demo_inputs.jsonl --output Assignment_3/results/demo_predictions.jsonl

# Demo also defaults to the selected model.
python -B Assignment_3/scripts/demo.py

# Refresh final tables, replay the five checkpoints and rebuild the package.
python -B Assignment_3/scripts/finalize_results.py

python -B -m pytest tests Assignment_2/tests Assignment_3/tests -q
```

Earlier assignment source remains available:

- `src/eda/`: exploratory data processing and frozen embedding utilities.
- `src/baselines/` and `configs/baselines.yaml`: classical and frozen XLM-R baselines.
- `Assignment_2/`: BM25, dense retrieval, reciprocal rank fusion and evaluation.
- `Assignment_3/`: selected model, repeated-seed experiments, official evaluation, analysis tables, checkpoints and logs.
- `data/raw/dev/SV/`: original usages, definitions and labels; unchanged.

The fixed official evaluator is vendored with its pinned revision and hashes in `Assignment_3/vendor/official/`. It averages two-class macro F1 within each word, then across words. The five seeds are 42, 100, 2023, 2026 and 777. Exact-text grouping blocks duplicate contexts across training and evaluation; near-duplicate and source leakage are not ruled out.

No research paper, detailed report, slides or presentation is generated by the current Assignment 3 pipeline. Historical reports and retired source remain locally outside the final package.
