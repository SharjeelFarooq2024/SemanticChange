# Required baseline and ablation evidence

This folder contains the 210 baseline/ablation runs (21 configurations, five seeds, two split protocols), their fitted checkpoints, predictions, splits and fixed-evaluator results. It also supplies the pinned frozen representation caches used by the selected final model.

These are reference systems for the assignment comparisons. The selected model is in `../advanced_hybrid/`; canonical final results are in `../../results/` and the single distribution package is `../../final_package.zip`.
